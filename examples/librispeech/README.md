# Included reference: LibriSpeech 1272-128104-0000

`reference.flac` is an unmodified LibriSpeech dev-clean utterance, speaker 1272, chapter 128104. Original text: “Mister Quilter is the apostle of the middle classes and we are glad to welcome his gospel.”

LibriSpeech was prepared by Vassil Panayotov, Guoguo Chen, Daniel Povey and Sanjeev Khudanpur. The corpus is distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) by [OpenSLR, resource 12](https://www.openslr.org/12).

The small file was obtained from the [Qwen-Audio example copy](https://github.com/QwenLM/Qwen-Audio/blob/b50fb958438081d36e1a14e93dbbc2f329c7f10e/assets/audio/1272-128104-0000.flac). The [transcript is also provided by Qwen-Audio](https://github.com/QwenLM/Qwen-Audio/blob/b50fb958438081d36e1a14e93dbbc2f329c7f10e/assets/sft_sample.txt). The recording has not been edited. The target script is new project text.

This open example exercises the reference-to-WAV workflow. The earlier Japanese A/B/C benchmark uses different, private reference recordings; its timings and voice quality do not describe this example.
